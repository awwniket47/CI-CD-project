What it does

From one question to a full research report — automatically

Search the web

Researcher agent dispatches 3+ Tavily queries and gathers live data from authoritative sources.

🧠

Extract insights

Analyst agent uses Gemini 2.0 Flash to identify 5–7 key insights, statistics, and company examples.

Agent Architecture
Three autonomous agents.
Sequential, transparent, reliable.

Built with CrewAI and LangChain. Each agent is purpose-built, receives output from the previous, and passes its result forward. Every step streams live.

Agent 01 — Researcher
🔍

Researcher

Dispatches 3+ parallel Tavily web searches, collects and deduplicates 10–15 source articles, and structures raw data for the analyst. Streams every query result via SSE.

Tavily API LangChain Tool SSE Streaming CrewAI Agent
Agent 02 — Analyst
🧠

Analyst

Receives raw search data, sends it to Google Gemini 2.0 Flash, and extracts 5–7 key insights: market statistics, adoption rates, company case studies, and forward projections.

Gemini 2.0 Flash Insight Extraction LangChain Structured Output
Agent 03 — Writer
✍️

Writer

Takes analyst insights and drafts a 600+ word professional research report in structured markdown — with Executive Summary, Market Analysis, Case Studies, and Recommendations.

Gemini 2.0 Flash Markdown Output 600+ Words ChromaDB Save

Features
Everything built in

Research, deployment, and operations — all automated. No manual steps required from code to production.

⚡

Live SSE Streaming

Agent progress streams to the browser in real time via Server-Sent Events. Watch agents think — no polling, no refresh.

🧠

Gemini 2.0 Powered

Google Gemini 2.0 Flash drives all three agents via LangChain + CrewAI. Professional reports under 2 minutes.

🔍

Semantic Search

ChromaDB stores every report as a vector embedding (all-MiniLM-L6-v2). Find related reports by meaning, not just keywords.

🚀

Automated CI/CD

Three GitHub Actions workflows. Tests, Docker builds, and EC2 deploy happen automatically on every merge to main.

⏪

Versioned Rollback

Every deployment tagged by git SHA. Roll back to any previous version in under 60 seconds — directly from GitHub Actions.

💾

Dual Knowledge Store

Reports saved to ChromaDB for vector search AND as a .txt backup. Zero data loss. Always searchable.

❤️

Health-Checked Deploys

The /api/health endpoint confirms every new container is live before the old one is removed. True zero-downtime.

🐳

Fully Containerized

Multi-stage Docker builds for backend and frontend. SHA-tagged images on Docker Hub. Runs anywhere.

🔐

Secrets-Only Credentials

All API keys and SSH credentials managed via GitHub Secrets. Nothing sensitive in source code or Docker images.
