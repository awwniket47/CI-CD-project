How it works

One query. Three agents.
A complete report.

The system handles everything automatically — from web search to writing and storing the final report.

STEP 01
💬
You ask a question
Type any retail industry question — trends, technologies, strategies, market analysis. Natural language understood.
STEP 02
🔍
Agents search & analyse
The Researcher runs 3+ Tavily queries. The Analyst extracts 5–7 key insights with statistics and real company examples.
STEP 03
📄
Report saved forever
The Writer produces a 600+ word structured report. Saved to ChromaDB as a vector embedding — semantically searchable forever.
DevOps & CI/CD

Production-grade deployment on AWS EC2

Three GitHub Actions workflows automate the entire lifecycle — testing, building Docker images, and deploying on every merge to main.

Every deployment is immutably tagged with its git SHA on Docker Hub. Roll back to any previous version in under 60 seconds directly from GitHub Actions.

Features

Everything built in

Research, deployment, and operations — all automated.

⚡
Live SSE Pipeline
Agent progress streams to the browser in real time via Server-Sent Events — no polling required.
🧠
Gemini 2.0 Powered
Google Gemini 2.0 Flash drives all three agents via LangChain + CrewAI. Professional reports in minutes.
🔍
Semantic Search
ChromaDB stores every report as a vector embedding using all-MiniLM-L6-v2. Find conceptually related reports.
🚀
Automated CI/CD
Three GitHub Actions workflows run tests, build Docker images, and deploy to EC2 on every merge to main.
⏪
Versioned Rollback
Every deploy tagged with its git SHA. Roll back to any version in under 60 seconds from GitHub Actions.
💾
Dual Knowledge Store
Every report saves to ChromaDB for semantic search and as a .txt file for human-readable backup.
